Overview

Goethe A2 is the most complete trainer in the set: mock exams for the Goethe A2 paper, spaced-repetition flashcards, interactive grammar, and audio pronunciation for every word. Listening practice uses real dialogue rather than isolated sentences, speaking gets pronunciation feedback, and the whole thing works offline — so a train with no signal is still study time.

Questions

Before you download Goethe A2.

Is this an official Goethe-Institut app?
No. Goethe A2 is an independent study app built by Melih Firat. It is not affiliated with, endorsed by, or connected to the Goethe-Institut, and it does not issue certificates.
Does Goethe A2 work offline?
Yes. The app has an offline mode, so vocabulary, grammar and flashcards keep working without a connection.
Is there audio for pronunciation?
Yes — A2 vocabulary comes with audio pronunciation, and the speaking practice gives pronunciation feedback.
What does it cost?
The app is free to download and use, with an optional Pro upgrade that unlocks the full set of content.
Which devices does it run on?
iPhone and iPad, on iOS. There is no Android or web version.
